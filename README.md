# Tools

个人实用工具集。针对日常工作里反复出现的琐碎问题，做成开箱即用的轻量小工具。每个工具都是一个独立的静态页面，**无构建、无依赖、打开即用**。

## 设计约定

- 单文件 HTML，内联样式与脚本，双击即可在浏览器打开
- 界面统一为 Apple 系极简风格：浅灰底、白卡片、系统字体、克制的强调色
- 一个工具只解决一个具体问题，不堆功能
- 涉及需要精密度的工程场景（如印刷色）时，会在界面内如实标注精度与限制，不做误导
