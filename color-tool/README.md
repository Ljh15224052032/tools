# color-tool · RGB→CMYK 校色

把设计里的 RGB 颜色（如 Figma 色号）一键转成印刷用 CMYK，并提供接近真实印刷的观感对比，帮助你判断颜色送印后会不会偏。

## 使用

- 直接双击 `index.html`，在浏览器打开即可，无需安装与构建
- 目标色输入方式：HEX 色号 / 原生色盘 / 拖 RGB 滑块 / 屏幕取色（Chromium 系浏览器）

## 功能

- RGB → CMYK 数值转换（标准减法混色）
- 一键复制 CMYK / HEX 数值
- 印刷观感模拟：Beer-Lambert 减色吸收 + Murray-Davies 网点增益 + 纸张白点 + 油墨不纯
- 超色域警告：判断颜色能否用四色油墨印出，印不出来的会高亮并提示改用专色
- 校对色：复制转换结果后手动微调 C/M/Y/K，实时对比目标色

## 精度与限制

屏幕只能发 RGB 光、纸张反射油墨，物理上无法完全一致。本工具不含任何 ICC 配置文件，仅按涂布纸粗略近似模拟印刷观感，换打印机或纸张即失效。它不是精确打样，不能作为定版依据。

要真正准确：向工厂索要 ICC 配置文件，在 Photoshop「视图 → 校样设置」中软打样；关键色做实物打样，或改用专色 Pantone。
