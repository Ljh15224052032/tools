# 印刷对色实操 SOP —— 工厂不给 ICC 时，用公开标准替代

> 适用：工厂不提供自己的 ICC 文件（大多数小厂如此），但会告诉你「我按某个标准走」。
> 思路：把公开的标准 ICC 装进你的软件 → 屏幕软打样 → 自己预览并微调，尽量贴近工厂实际。

---

> 🚀 **本工具已内置「ICC 真打样」。** 顶部「软打样模式 → ICC 真打样」，直接载入下方任一标准 ICC（或工厂给的文件），网页就用**真实 ICC 引擎**（jscolorengine2，LittleCMS 同源血统）打样：CMYK build、纸张观感、色差 ΔE2000 全按该标准计算，全程本地不上传。未载入时仍走内置「近似模拟」，秒开兜底。**最终仍以校准后的实物合同样为准（精度受显示器校准影响）。**

---

## 一、先确认工厂走什么标准（一句话问清）

| 工厂回答 | 你要用的标准 ICC |
|---|---|
| 国内 / 铜版纸 / 按 ISO | **ISO Coated v2 · FOGRA39** |
| 较新的欧洲标准 | **ISO Coated · FOGRA51** |
| 美国规格 / 出版 | **US Web Coated (SWOP) v2** |
| 哑粉 / 胶版纸 / 白卡 | **ISO Uncoated v2 · FOGRA29** |

**话术（直接照抄发给工厂）：**
> 「你们的印刷按哪个色标准走？FOGRA39 / FOGRA51 还是 SWOP v2？我按对应 ICC 软打样对色。」

> ⚠️ 标准选不对，高饱和处就会偏。国内小厂若说不清楚，**默认先按 FOGRA39（涂布）或白卡纸对应标准**试，实物打样复核。

---

## 二、下载公开 ICC（免费）

几个可用的官方来源：

| 来源 | 说明 |
|---|---|
| **eci.org** | ECI 官方，FOGRA39 / FOGRA51 / FOGRA29 等一应俱全 |
| **color.org** | 国际色彩联盟官网，有标准 profile 与教程 |
| **印刷厂官网支持页** | 部分会提供对应 .icc/.icm 供下载 |

拿到 `.icc` 或 `.icm` 文件后，双击安装（Windows 会自动装进系统色彩配置）。

---

## 三、在 Photoshop / Illustrator 里软打样（自己预览 + 调整）

> 这是「你完全可控」的核心动作：看到的就是「印出来大概长这样」，然后直接在这个视图里调色。

1. 打开文件（RGB 状态即可，不用先转 CMYK）
2. **Photoshop**：`视图 → 校样设置 → 自定义`
3. **Device to Simulate**：选刚装的 FOGRA / SWOP 标准 ICC
4. 勾选：
   - ✅ **模拟纸张颜色**（让屏幕变「纸白」）
   - ✅ **模拟黑墨**
   - 渲染意图：选 **相对色度**（印刷通用）
5. 按 **Ctrl+Y / Cmd+Y** 切换预览 → 满不满意直接在这个视图下微调颜色

> Illustrator / InDesign 路径相同（`视图 → 校样设置 → 自定义`）。

---

## 四、Acrobat 交付前总检

导出的 PDF 在 Acrobat 里：`工具 → 印刷制作 → 输出预览`，用同一 ICC 模拟最终印刷效果，**作为交付给工厂前的最后一道关**。

---

## 五、给工厂的硬性要求（可量化，别靠感觉）

| 项目 | 要求 |
|---|---|
| 标准 | 明确 FOGRA39 / 51 / SWOP v2 |
| 合同样 | 关键色 / 大货必做**实物合同样**，并附**测量证书** |
| ΔE 合格线 | 平均 ΔE < 3，单点最大 < 5 |
| 纸张 | 确认哑粉 / 铜版 / 白卡，**换纸标准可能不同** |

---

## 六、关键色兜底：Pantone 专色

某个颜色**绝不能跑偏**（Logo / 主色）时，直接改成**专色（Pantone）**：
- 专色是预调好的桶装专色油墨，跨机跨厂都准，能印 CMYK 印不出的色
- 多一个专色版、更贵，**只在关键色上用**

在改专色前，可先用工具里的「最近专色参考」找对应的 PMS 号，再向工厂确认其相应 CMYK build。

---

## 七、完整检查清单

- [ ] 问清工厂标准（FOGRA39 / 51 / SWOP v2）
- [ ] 校准显示器（亮度 ~100cd/m²、白点 D50、Gamma 2.2，每月一次）
- [ ] 下载、安装对应的公开 ICC
- [ ] PS/Illustrator 软打样：自定义校样设置 + 模拟纸白/黑墨
- [ ] Acrobat 输出预览总检
- [ ] 关键色定版前要**实物合同样 + ΔE 证书**
- [ ] 兜底：关键色改用 Pantone 专色
