方向性筛查，非精确打样
本工具用于方向性筛查，不能在屏幕上真实还原印刷色。任何网页模拟（含本工具）都无法替代 ICC 软打样与实物打样。

精确匹配印刷效果，并据此定版不可靠 · 勿定版
为何达不到高精度：屏幕发 RGB 光、纸张反射油墨，两者物理上无法一致；本工具不含 ICC 配置，仅按涂布纸粗略近似，换打印机或纸张即失效。即使使用正确 ICC + 校准显示器，行业标准通常也只有 ΔE≈2–5，并非"95% 一致"。
要真正准确，请： 1. 向工厂索要其 ICC 配置文件，在 Photoshop 「视图 → 校样设置」中软打样 2. 关键色做实物打样（contract proof） 3. 关键色改用专色 Pantone，而非流程四色
